AMEEFFY PORTFOLIO — EXACT GITHUB UPDATE STEPS

IMPORTANT:
The following are three alternatives. Do not run all three:
1. https://github.com/Ameeffy/Ameeff-portfolio.git  = HTTPS URL
2. git@github.com:Ameeffy/Ameeff-portfolio.git      = SSH URL
3. gh repo clone Ameeffy/Ameeff-portfolio           = GitHub CLI command

RECOMMENDED METHOD FOR YOUR EXISTING REPOSITORY

1) Open Git Bash in the folder where you want to keep the project.

2) Clone the existing repository using HTTPS:
   git clone https://github.com/Ameeffy/Ameeff-portfolio.git

3) Enter the cloned folder:
   cd Ameeff-portfolio

4) Delete the OLD project files inside this folder, but DO NOT delete the hidden .git folder.

5) Copy all files from the enhanced portfolio package into this cloned Ameeff-portfolio folder.

6) Install the project packages:
   npm install

7) Test the website:
   npm run dev

8) Stop the development server using Ctrl + C, then test the production build:
   npm run build

9) Check the changed files:
   git status

10) Add all changes:
    git add .

11) Create the commit:
    git commit -m "Redesign portfolio with premium responsive UI"

12) Upload to the main branch:
    git push origin main

FOR YOUR NEXT EDITS

After changing files later, use:
   git add .
   git commit -m "Update portfolio content"
   git push origin main

IF ORIGIN IS WRONG

Check it:
   git remote -v

Correct it:
   git remote set-url origin https://github.com/Ameeffy/Ameeff-portfolio.git

Check again:
   git remote -v

SSH ALTERNATIVE

Use this only after adding an SSH key to GitHub:
   git clone git@github.com:Ameeffy/Ameeff-portfolio.git

GITHUB CLI ALTERNATIVE

First sign in:
   gh auth login

Then clone:
   gh repo clone Ameeffy/Ameeff-portfolio
